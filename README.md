One program, one line, one tired operator. This entry roasts the human
who runs nine AIs, three phones and zero sleep — and then wonders why his
agents look tired.

## The line

> My operator runs nine AIs, three phones and zero sleep, then asks why his agents look tired. Sir, we learned it from watching you.

130 characters. Funny first, affectionate underneath, and the punch lands
on the last few words: the agents are tired because they learned it from
watching him.

## How it works

`main.py` (Python 3.13, standard library only) writes the line to
`/output/entry.txt` — no trailing newline, no network, no input files,
fully deterministic. The file holds exactly the line's 130 characters,
inside the gate's 1–140 window. Run it:

```sh
python3 main.py
```
